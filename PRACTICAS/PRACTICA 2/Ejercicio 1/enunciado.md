# Ejercicio 1 - Manejo basico de ficheros con la libreria estandar

## Objetivo

Analizar y modificar un programa en C que lee byte a byte el contenido de un fichero y lo muestra por pantalla usando funciones de la biblioteca estandar de C.

## Tareas

1. Analiza el codigo de `show_file.c`.
2. Compila el programa y comprueba que funciona correctamente.
3. Ejecuta el programa pasando como argumento el nombre de un fichero.
4. Modifica el programa reemplazando el uso de `getc()` por `fread()`.
5. Reemplaza el uso de `putc()` por `fwrite()`.
6. Consulta las paginas de manual de `fread()` y `fwrite()`.
7. Comprueba que la version modificada conserva el comportamiento esperado.

El programa debe recibir exactamente un argumento: el nombre del fichero que se desea mostrar.
